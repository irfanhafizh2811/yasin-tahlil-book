## 🎯 Visual Philosophy & Art Direction

### 🕌 Islamic Art Principles

**Core Visual Values**:
1. **Sacred Geometry**: Using traditional Islamic geometric patterns as foundation
2. **Spiritual Abstraction**: Avoiding figurative representation in religious contexts
3. **Light & Transcendence**: Emphasizing divine light and spiritual elevation
4. **Cultural Unity**: Visual language that connects global Muslim community
5. **Reverent Beauty**: Honoring the sacred nature of memorial prayers

**Artistic Guidelines**:
- **No Animate Beings**: Following Islamic artistic traditions, no human or animal figures in spiritual contexts
- **Geometric Harmony**: Based on traditional Islamic mathematical patterns
- **Color Spirituality**: Using colors with Islamic significance and cultural meaning
- **Light Symbolism**: Divine light, guidance, and spiritual ascension themes
- **Nature Abstraction**: Gardens, water, and paradise imagery appropriately stylized

  welcomeLight: function() {
    const lightRays = document.querySelectorAll('.light-ray');
    lightRays.forEach((ray, index) => {
      ray.style.animation = `lightPulse ${2000 + (index * 200)}ms ease-in-out infinite alternate`;
    });
  },
  
  // Animate prayer counter demonstration
  prayerCounter: function() {
    const counter = document.querySelector('.prayer-counter-demo');
    const beads = document.querySelectorAll('.prayer-bead');
    
    let count = 0;
    const interval = setInterval(() => {
      if (count < beads.length) {
        beads[count].classList.add('counted');
        count++;
      } else {
        clearInterval(interval);
        setTimeout(() => {
          beads.forEach(bead => bead.classList.remove('counted'));
          count = 0;
        }, 1000);
      }
    }, 150);
  },
  
  // Animate community connection
  communityConnection: function() {
    const connections = document.querySelectorAll('.community-connection');
    connections.forEach((connection, index) => {
      connection.style.animationDelay = `${index * 0.5}s`;
      connection.classList.add('pulse-connection');
    });
  }
};
