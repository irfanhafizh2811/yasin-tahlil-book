# 📚 Yasin & Tahlil App - Project Documentation Hub

## 📋 Project Overview
**Project Name**: Tahlil - Yasin & Tahlil App  
**Project Type**: Mobile Application (Android/iOS)  
**Target Market**: Muslim community, especially Southeast Asia  
**Project Status**: Product Discovery & Design Phase  
**Started**: May 20, 2026  

---

## 🎯 Project Vision
Create a digital companion for **Malam Jumat** (Friday night) traditions, helping Muslims worldwide pray for their departed loved ones with **Yasin** and **Tahlil** readings, emphasizing **photo-centric memorial profiles** and **global community engagement**.

### Risk Mitigation
- **Technical Risk**: Offline-first architecture for reliable prayer access
- **Cultural Risk**: Religious scholar validation of all content
- **Market Risk**: Continuous user feedback and iteration
- **Competition Risk**: Unique memorial focus differentiates from generic prayer apps

---

## 📝 Key Decisions Made

### Product Decisions
1. **Photo-Centric Design**: Memorial photos are hero elements in all interfaces
2. **Freemium Model**: Free basic features with premium family sharing
3. **Offline-First**: App must work without internet for core prayer functions
4. **Cultural Authenticity**: All content validated by Islamic scholars

### Technical Decisions
1. **Android First**: 70% of target market, faster time to market
2. **MVVM Architecture**: Scalable and maintainable code structure
3. **Room + Firebase**: Local-first with cloud synchronization
4. **Minimum API 24**: Balance between reach and modern features

### Design Decisions
1. **3-Tap Rule**: Core actions achievable in maximum 3 taps
2. **Adaptive Themes**: Context-aware UI based on time and day
3. **Large Touch Targets**: Accessibility for elderly users
4. **Progressive Disclosure**: Simple interface with advanced features hidden
