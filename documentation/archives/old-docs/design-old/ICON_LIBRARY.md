## 🎯 Islamic Icon Design Principles

### 🕌 Cultural Appropriateness Guidelines

1. **No Animate Beings**: Avoid human or animal representations in religious contexts
2. **Geometric Patterns**: Emphasize Islamic geometric art traditions
3. **Calligraphic Elements**: Incorporate Arabic script and calligraphy respectfully
4. **Universal Symbols**: Use globally recognized Islamic symbols appropriately
5. **Regional Sensitivity**: Adapt icons for different cultural interpretations

### 🎨 Visual Design Standards
- **Line Weight**: 2dp stroke for optimal clarity
- **Corner Radius**: 2dp for subtle softness
- **Fill Style**: Outlined with optional solid variants
- **Color Palette**: Follows Tahlil brand colors
- **Scalability**: Optimized for 16dp to 96dp sizes


```
Accessibility:

❌ Avoid: Color-only communication, unclear symbols

✅ Use: Tahlil color palette, consistent line weights
```
